# ARENA DROP — BETA LAB

Esta branch contém uma área experimental separada da versão principal.

## Abrir
Depois que o GitHub Pages concluir o deploy da branch beta:
- Página principal: https://tarachukalucas-cyber.github.io/arena-drop/
- Laboratório beta: https://tarachukalucas-cyber.github.io/arena-drop/beta.html

## O que testar nesta primeira etapa
- movimentação em terceira pessoa;
- câmera por mouse ou toque;
- controles de movimento em telas touch;
- colisões simples com construções;
- área de exposição para A5 Base, X50 Prism e Armor Breaker.

## Estado dos modelos
Os três itens ainda aparecem como espaços de teste. Os arquivos ZIP enviados precisam ser convertidos/extraídos em modelos GLB e adicionados ao repositório antes de aparecerem como modelos 3D reais nesta cena.

## Limites desta beta
- sem bots;
- sem partida multiplayer nesta área de teste;
- personagem e cenário usam proxies geométricos temporários;
- inventário nesta etapa é apenas seleção visual;
- ainda não é uma build final nem foi validada em celular físico.

A branch beta é separada de main para permitir testes sem substituir a versão principal.
